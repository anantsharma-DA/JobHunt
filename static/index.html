Company careers sites

Add companies to include in every search (when Company sites is ticked). Paste the company's careers link if it is on Greenhouse, Lever, Ashby, SmartRecruiters or Workday (open any job on their careers page; if the address contains greenhouse.io, lever.co, ashbyhq.com, smartrecruiters.com or myworkdayjobs.com, paste it). For any other careers link, the app looks inside that page for one of these platforms and reads it if found. If none is found, or there is no link, it searches Indeed, LinkedIn or both (choose on the Settings tab) for your job titles plus the company name and keeps only that company's jobs.

Good to know

  • Naukri blocks automated requests, so Naukri searches run in a Microsoft Edge window placed off-screen. You may see Edge in the taskbar during a search; don't close it.
  • LinkedIn limits how many searches it allows. If it shows "blocked", wait 30–60 minutes and search again.
  • Job sites change their pages from time to time. If a source stops working, update JobSpy: .venv\Scripts\python -m pip install -U --no-deps python-jobspy
  • Companies with their own custom careers sites are only covered as far as they post jobs on Indeed or LinkedIn. For a long company list, choose "Indeed only" above so LinkedIn doesn't block your main search.
  • The app runs only while the run.bat window is open.
